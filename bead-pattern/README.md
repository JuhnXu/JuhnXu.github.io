# 拼豆图纸生成器 v1

纯前端静态网页，将图片转换成拼豆图纸。

## 使用
直接打开 `index.html` 即可，也可以部署到 GitHub Pages、Nginx、任意静态网站。

## 功能
- 本地图片上传 / 拖拽
- 保持比例自动计算图纸尺寸
- 5~200 格宽高
- 4~48 色量化
- 内置常用色板 / 基础 12 色板
- 图纸网格
- 可选颜色编号
- 颜色数量统计
- PNG 图纸导出
- CSV 颜色统计导出
- 图片不会上传服务器

## 后续可扩展
- Perler / Hama / Artkal 官方色板
- PDF 多页打印图纸
- A4 自动分页
- 颜色替换与手动点选
- 背景透明 / 去背景
- 图纸坐标轴
- 拼豆成本估算
