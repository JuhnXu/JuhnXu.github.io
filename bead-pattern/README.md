# 拼豆图纸生成器 v1.2.1

纯前端静态网页，将图片转换成拼豆图纸。

## 使用
直接打开 `index.html` 即可，也可以部署到 GitHub Pages、Nginx、任意静态网站。

## 功能
- 本地图片上传 / 拖拽
- 保持比例自动计算图纸尺寸
- 5~200 格宽高
- 4~48 色量化
- 内置常用色板 / 基础 12 色板
- 图纸网格
- 可选颜色编号
- 颜色数量统计
- PNG 图纸导出
- CSV 颜色统计导出
- 图片不会上传服务器

## 后续可扩展

## v1.1.0：按图片分辨率调整拼豆数量与尺寸
- 上传后读取原图宽高像素和总像素数。
- 新增「按拼豆宽度」：指定宽度格数，高度按原图比例自动计算。
- 新增「按拼豆总数量」：输入目标拼豆总数，自动推算接近原图比例的宽高。
- 新增「按实物拼豆尺寸」：输入单颗拼豆毫米尺寸，自动生成对应图纸规格并显示成品厘米尺寸。
- 最大图纸规格提升到 300 × 300。
- 图纸预览明确显示“原图像素 → 拼豆格数”。
- 颜色统计和总拼豆数随分辨率/尺寸变化实时更新。

### 尺寸逻辑
图纸不是简单把原图每一个像素都变成一颗拼豆，而是先根据目标拼豆格数将原图缩放采样，再将每格颜色映射到色板。因此：
- 原图分辨率越高，不代表必须使用同样数量的拼豆；
- 图纸格数决定最终拼豆数量和细节级别；
- 保持比例时，宽高会根据原图宽高比自动计算；
- 实物尺寸 = 拼豆格数 × 单颗拼豆尺寸。

## v1.2.0：原图 + 网格模式
新增「原图 + 网格（不改变原图）」模式。

- 原图颜色完全保留，不进行颜色量化。
- 原图上直接叠加拼豆网格。
- 网格列数可手动调节 5～200 格，高度根据原图比例计算。
- 可调网格线强度。
- 可调网格线宽度。
- 导出的 PNG 为“原图 + 网格”，不会把原图转换成色板颜色。
- 该模式不会生成颜色清单，因为原图没有被修改成拼豆色板。
- 原来的「拼豆图纸（颜色量化）」模式保持不变。
